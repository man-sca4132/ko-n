# EMMS BET v2

## Run locally
1. Install Node.js 18+.
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000`.

Demo user: user@emmsbet.test / password123
Demo admin: admin@emmsbet.test / admin123

The API uses in-memory demo data, so it resets when the server restarts.

Payment endpoints are sandbox-only and do not move real money.
